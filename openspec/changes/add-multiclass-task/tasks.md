## 1. Tâche et métriques

- [x] 1.1 Créer `ia_xp_plateform/task/multiclass.py`. `probabilities` renvoie le softmax. `predict` renvoie l'argmax avec `keepdim=True` et ignore le seuil. `loss` appelle `CrossEntropyLoss` après avoir exigé des logits `(N, K)` avec `K >= 2`, une cible `(N, 1)` ou `(N,)`, et des indices entiers dans `0 .. K-1`. Une valeur à moins de `1e-5` de son entier est cet indice. Une perte autre que `cross_entropy` lève `ValueError` en citant `cross_entropy`. Vérifier dans `test/unitaire/test_multiclass_task.py` : les logits `0, 0, 0` donnent trois probabilités `1/3` et, avec la cible `0`, une perte `log(3)` ; les logits `0, 5, 1` donnent la classe `1` aux seuils `0.1` et `0.9` ; les logits `2, 2, 0` donnent la classe `0` ; les logits `80, 0, 0` et la cible `1` donnent une perte finie et strictement positive ; la cible `2.0` avec trois logits donne une perte finie ; la cible `3` lève une erreur qui contient `0` et `2` ; la cible `1.5` est refusée ; un seul logit est refusé en nommant ce nombre. Lancer `poetry run pytest -q test/unitaire/test_multiclass_task.py`.
- [x] 1.2 Créer `MulticlassClassificationMetrics`. `update` reçoit des probabilités `(N, K)` et des indices `(N,)`, et accumule la matrice `K×K` de l'époque. `compute` rend `acc`, `precision`, `recall`, `f1` et `mcc`, sans clef `ap`. La précision, le rappel et le F1 sont la moyenne des `K` classes, une classe sans compte valant 0. Le MCC suit la formule de la spec, et un dénominateur nul donne 0. `reset` remet la matrice à zéro. Vérifier dans `test/unitaire/test_multiclass_metrics.py` : prédictions `0, 0, 1` et cibles `0, 1, 1` avec `K = 3` donnent une justesse `2/3`, une précision macro `1/2`, un rappel macro `1/2`, un F1 macro `4/9`, et la matrice `[[1, 0, 0], [1, 1, 0], [0, 0, 0]]` ; une prédiction parfaite donne un MCC de 1 ; une seule classe des deux côtés donne un MCC de 0 ; `reset` ramène la justesse à 0. Lancer `poetry run pytest -q test/unitaire/test_multiclass_metrics.py`.
- [x] 1.3 Enregistrer `multiclass` dans `TASKS`. `create_task(name, loss=None)` utilise le défaut de la classe quand `loss` est absent : `bce` pour `binary`, `cross_entropy` pour `multiclass`.
